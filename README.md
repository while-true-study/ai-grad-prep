# AI Graduate School Preparation

AI 대학원 준비를 위한 머신러닝·딥러닝 학습, PyTorch 구현 및 AI 연구 실험 기록 저장소입니다.

## Study Areas

### Dive into Deep Learning

D2L을 기반으로 딥러닝 핵심 개념을 학습하고 PyTorch로 직접 구현합니다.

### ML / Kaggle Practice

머신러닝 모델링과 데이터 처리, Kaggle 실습을 통해 실전 ML 파이프라인을 연습합니다.

### Research Experiments

향후 관심 연구 주제에 대한 논문 구현 및 실험을 기록합니다.
